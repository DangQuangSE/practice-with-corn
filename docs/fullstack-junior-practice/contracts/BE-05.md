# BE-05 — Field validation contract

## Request

```json
{ "name": "Notebook", "price": 4.5 }
```

`name` is required, non-blank, and at most 80 characters. `price` is required and non-negative. Validation is performed by the backend even if the frontend also checks input for usability.

## Invalid response

Return status 400 using the [BE-04 Problem Details contract](BE-04.md), with one `errors` item per invalid field. Do not return a successful empty object for invalid input.

## Independent checks

- BE: send blank/81-character names and negative prices.
- FE: mock multiple field errors and an unknown field; preserve values and make correction keyboard-accessible.
