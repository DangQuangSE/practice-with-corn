# BE-03 — CRUD, not-found, and conflict behavior

**Paired workspaces:** Phase 02 Java and Next.js foundations modules.

## Contract

- Create/update requests contain `name` and `price`.
- Names are unique after trimming and case normalization (the exact normalization rule must be documented by the exercise).
- Missing IDs return 404 Problem Details; duplicate names return 409 Problem Details.
- Successful create returns 201 and a `Location` header; update returns 200 with the response DTO.

## Independent checks

- BE: use two POST requests with equivalent names, then GET a nonexistent UUID.
- FE: simulate 201, 404, and 409 responses; show a recoverable message without rendering raw server internals.
