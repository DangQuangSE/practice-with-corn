# Java DSA Practice Plan

Bộ khung Java được tổ chức theo các chủ đề trong docs/dsa-practice.
Mỗi chủ đề chính có 10 bài:

- Bài 1-3: Easy
- Bài 4-10: Medium

Các file Java mới giữ phần solve() ở dạng TODO, có ví dụ test trong main()
để bạn tự viết lời giải rồi chạy java TenFile.java.
